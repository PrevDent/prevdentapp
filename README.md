# 🦷 PrevDent

**PrevDent** é um aplicativo mobile voltado para o **acompanhamento preventivo da saúde bucal**, permitindo o registro e o monitoramento de ocorrências odontológicas, agendamento de consultas e acesso ao histórico clínico dos pacientes.

Desenvolvido com **React Native** e utilizando tecnologias modernas de frontend e backend, o PrevDent oferece uma solução prática e eficiente para profissionais da área odontológica, clínicas e pacientes.

---


## 🧩 Funcionalidades

- 🔹 Cadastro e login de usuários com autenticação JWT
- 📋 Registro de ocorrências odontológicas (tipo, intensidade, observações)
- 🗓️ Agendamento de consultas com escolha de especialidade, dentista e horário
- 🧾 Visualização de histórico de registros e agendamentos
- 👨‍⚕️ Detalhamento das áreas de atuação odontológicas
- 📊 Interface moderna, com modais personalizados e navegação fluida

---

## 🛠️ Tecnologias Utilizadas
